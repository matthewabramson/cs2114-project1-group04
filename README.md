# cs2114-project1-group04 - Lucky 21
# Description

Lucky 21 is a Java-based version of Blackjack. The player places a bet and receives two cards, while the dealer receives one card.

The player can choose to hit or stand. If the player hits, they receive another card. If the player stands, the dealer draws cards until the dealer's hand reaches 17 or higher. The objective of the game is to get as close to 21 without going over, which will result in an immediate loss. 

The game keeps track of wins, losses, and pushes.

## How to Compile and Run

1. Add student.jar to build path for JUnit Tests
2. right click on BlackjackGame.java
3. select Run As -> Java Application
4. The game will start in the console
5. Choose hit or stay when prompted
6. After the round ends you will be asked to play again or leave
7. After leaving your wins, losses, and pushes will be displayed
